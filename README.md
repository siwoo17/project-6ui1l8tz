# Гагик — искусство массажа

Адаптивный сайт частной практики массажа: направления, полный прайс из 22 услуг, информация о мастере, отзывы, ответы на вопросы и контакты.

## Разработка

Node.js 20.18.1+ и npm. Установить зависимости и запустить:

```sh
npm ci
npm run dev
```

Vite слушает порт 5173 на всех интерфейсах. Секреты, база данных и внешние API для запуска не требуются. Шрифты и фотографии включены в проект.

```sh
npm run lint
npm run typecheck
npm test
npm run format:check
npm run build
```

`npm run preview -- --port 4173` запускает просмотр production-сборки. Каталог `dist` можно разместить на статическом хостинге.

## Контент и запись

- `src/services.ts`: все услуги, категории, продолжительность и цены. Двойные цены сохранены, отсутствующая в оригинале длительность детского общего массажа не подставляется.
- `src/App.tsx`: контакты, отзывы, информационные разделы. Запись открывает диалог с выбором услуги и звонком мастеру; сайт не принимает заявки и не утверждает, что время забронировано.
- `src/styles.css`: адаптивный дизайн, клавиатурный фокус, поддержка reduced motion.
- `public/price-list.jpg`: предоставленный пользователем оригинал прайса.
